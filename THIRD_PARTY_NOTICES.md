# Third-party data notices

Vlot Vlaams is original application code released under the MIT License. Its generated vocabulary dataset incorporates and transforms open linguistic data:

- **FrequencyWords Dutch 2018** by the FrequencyWords contributors, derived from OpenSubtitles. The source repository identifies the dataset under CC BY-SA 4.0: <https://github.com/hermitdave/FrequencyWords>.
- **Kaikki.org Dutch machine-readable dictionary**, extracted from English Wiktionary by Wiktextract. Wiktionary text is available under CC BY-SA 4.0: <https://kaikki.org/dictionary/Dutch/>.
- **Tatoeba English–Dutch parallel sentences**, distributed through OPUS under CC BY 2.0 FR: <https://opus.nlpl.eu/Tatoeba.php> and <https://tatoeba.org/>.

The generated file `data/words.js` keeps source labels on every entry. The 50 Belgian-Dutch entries and their example sentences were independently curated for this project using public language guidance, including the Dutch Language Institute/Taalunie reference material and Flemish language-advice resources.

The optional YouTube Sentence Lab uses Jina AI Reader to request the public page or public caption endpoint for the YouTube URL entered by the learner. No account data or private video access is requested.

The A0–C1 labels in this app are curriculum bands, not official CEFR certifications or official word-level assignments.
